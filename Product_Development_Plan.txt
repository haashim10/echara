Goal:  Deliver MVP across Buyer, Vendor, and Admin experiences for Echara (cross -
platform + web).  
 MVP Duration:  ~12 weeks total, across 4 major sprints.  
 AI Recommendations & Stripe Payments:  deferred to Phase 2.  
 Admin:  web -only.

🧭 Reporting & Workflow Guidelines  
• Branch naming:  feature/<epic> -<story>  
• Commit style:  Conventional commits (feat:, fix:, chore:)  
• Jira states:  Backlog → In Progress → Code Review → QA → Done  
• Definition of Done:  
o All AC met  
o Unit tests pass  
o API documented in Swagger  
o Screens responsive  
o Accessibility check passed  
o No console errors
